\chapter{Sustainability Analysis}
\label{chap:sustainability-analysis}

This chapter evaluates \gls{SafeVision} using the Sustainability Awareness Framework (\acrshort{susaf}). It is a question based framework for identifying how software systems may affect sustainability across different dimensions and time horizons \cite{duboc2020requirements}. This is relevant for \gls{SafeVision} because the system affects privacy work, user effort, resource use, long-term cost, and technical maintenance. The full dimension by dimension assessment is provided in Appendix~\ref{app:sustainability_analysis}.

\section{Relation to the United Nations (\acrshort{un}) Sustainable Development Goals (\acrshort{sdg})}
\label{sec:sdg_relation}

In addition to the \acrshort{susaf}, SafeVision can be related to selected \acrshort{un} \acrshort{sdg}s. This relation does not mean that the system directly fulfills these goals, but rather that the project connects to broader sustainability themes through privacy, digital workflows, resource use, and responsible information handling.

\gls{safevision} is mostly connected to \acrshort{sdg}~9, Industry, Innovation and Infrastructure, which concerns resilient infrastructure, inclusive and sustainable industrialization, and innovation \cite{un_sdg9}. The project explores how machine learning and web technologies can support improved digital infrastructure for visual redaction. By combining automated detection with user guided refinement, \gls{safevision} provides a more scalable and adaptable approach to handling sensitive visual media.

The project also relates to \acrshort{sdg}~16, Peace, Justice and Strong Institutions, which includes themes such as accountability, access to justice, and effective institutions \cite{un_sdg16}. In the context of \gls{safevision}, this connection is mainly reflected in the system's support for privacy, accountability, and responsible information handling. Visual media may contain personal information such as faces, license plates, and readable text. By helping users identify and anonymize such content before sharing or publication, \gls{safevision} can support safer handling of sensitive information and reduce the risk of accidental disclosure.

Finally, \gls{safevision} has an indirect connection to \acrshort{sdg}~12, Responsible Consumption and Production, which concerns sustainable resource use and responsible production patterns \cite{un_sdg12}. The system may reduce repetitive manual work and support more efficient use of organizational resources. At the same time, \acrshort{ml} based processing introduces computational costs, especially when heavier models, segmentation, or cloud infrastructure are used. This means that the sustainability value of the system depends on balancing workflow efficiency against resource use. These trade offs are discussed further in the detailed sustainability assessment in Appendix~\ref{app:sustainability_analysis}.

\section{Sustainability Dimensions}
\label{sec:susaf_dimensions}

\methodheading{Individual Dimension}

\gls{SafeVision} reduces repetitive manual work in image redaction. Instead of searching the entire image manually, users can review detected regions and adjust them when necessary. This supports faster redaction and review, while making the workflow more accessible to users without specialist image-editing knowledge.

\methodheading{Social Dimension}

The main social benefit is improved privacy protection. By helping users identify and redact sensitive visual information before external use, \gls{SafeVision} can reduce the risk of accidental exposure. Over time, it may also support more standardized privacy workflows, where redaction becomes a regular part of handling visual media rather than an inconsistent individual practice.

\methodheading{Technical Dimension}

The technical dimension is closely connected to the system architecture. \gls{SafeVision}'s modular design makes it easier to update, test, or replace individual components without redesigning the entire system. However, the use of \acrshort{ml} introduces long-term technical responsibility. Detection performance may change when input data, image quality, or use cases change, which creates a continued need for testing, monitoring, and model updates.

\methodheading{Economic Dimension}

\gls{SafeVision} can reduce labor cost by automating parts of the redaction process and supporting faster review. This may make it easier to handle larger image volumes without increasing manual workload at the same rate. At the same time, these benefits depend on continued maintenance. Model updates, testing, infrastructure, and technical support may create recurring costs after deployment.

\methodheading{Environmental Dimension}

The environmental dimension contains both benefits and trade-offs. \acrshort{ml} \gls{inference} requires computational resources, which gives the system an immediate environmental cost. At the same time, more efficient redaction workflows may reduce the need to store or transfer unprocessed sensitive images. A possible long-term risk is a rebound effect, where easier redaction leads to more image data being processed and partly offsets the efficiency gains.


The (\acrshort{susaf}) model shows that \gls{SafeVision}'s sustainability depends on a balance between automation benefits and long-term responsibility. The system can improve privacy work by reducing manual effort, supporting more consistent redaction practices, and enabling scalable processing. These benefits are strongest when the system is used as a decision-support tool rather than as a fully autonomous solution. At the same time, the model highlights risks that must be managed after deployment, especially \gls{inference} energy use, model drift, testing effort, and recurring maintenance costs. \gls{SafeVision} should therefore be understood as a sustainability supporting system whose value depends on continued monitoring, responsible operation, and integration into controlled privacy workflows.
